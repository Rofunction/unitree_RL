- 日期：2026-08-29

## 1. 问题背景与现象

| 环境 | 现象 | 实测特征 |
|---|---|---|
| IsaacGym（训练/play） | 臂远端关节"锁死"，看似正常 | 腕 q̇ 读数恒 +41.6 rad/s（20 个策略步 0 次符号翻转），关节位移仅 0.02–0.19 rad，而目标摆动 0.4–1.1 rad；肩yaw 同样锁定（q̇ 恒 −27~−41，q ±0.17 rad） |
| MuJoCo 部署 @500Hz 物理 | 臂部剧烈乱摆，~0.5s 摔倒 | 腕位置游走 ±2.4 rad、子步 q̇ 达 255–291 rad/s；肩yaw 越过稳定边界后开始执行未训练的噪声指令 |
| MuJoCo 部署 @200Hz 物理 | 0.11s 数值爆炸 | MuJoCo 报 "Nan, Inf or huge value in QACC"，膝关节 q 飙至 1e4 量级；手臂零力矩也照样爆炸 → 源头在踝 |

锁死的本质：显式阻尼自激产生的周期 2 子步极限环，在力矩限幅的对称饱和下**净位移为零**——关节被"焊死"在原地。策略在训练中从未见过这些关节对指令的响应（聋通道），因此臂部动作输出从未被真正学习。

## 2. 两个仿真器的步长对照

β 公式中的 **dt 一律取"物理求解步长"**（= 显式力矩的重算周期，两个仿真器口径一致：力矩在每个物理步重算，见 `legged_robot.py` 的 `step()` 内 `for _ in range(decimation)` 循环，以及 `deploy_mujoco.py` 主循环里每个 `mj_step` 前的 `pd_control`）。

| 仿真器 | 配置来源 | 物理步长 dt | 物理频率 | 策略频率 | 备注 |
|---|---|---|---|---|---|
| IsaacGym（训练/回放） | `g1_23dof_config.py`：`sim.dt=0.005`、`decimation=4` | **0.005 s** | 200 Hz | 50 Hz | 所有 β 越界判断以此 dt 为准 |
| MuJoCo（部署，当前 yaml） | `g1.yaml`：`simulation_dt=0.002`、`control_decimation=10` | **0.002 s** | 500 Hz | 50 Hz | 策略周期同为 0.02 s |
| MuJoCo（部署，训练同频率选项） | `simulation_dt=0.005`、`control_decimation=4` | 0.005 s | 200 Hz | 50 Hz | 加 armature 后走得最久的组合 |

策略周期在三种配置下都是 0.02 s（50 Hz）；唯一的物理差异是求解步长，而 β 与 dt 成正比——这是"换个仿真器/频率行为突变"的直接原因。

## 3. 稳定性判据推导

### 3.1 纯阻尼情形：β = 2 的来源

被控对象只保留阻尼项：`I·v̇ = −Kd·v`。仿真器每步做显式欧拉更新：

```
v[n+1] = v[n] + dt·(−Kd·v[n])/I = (1 − β)·v[n]，   β ≡ Kd·dt/I
```

这是公比为 `1−β` 的等比数列。**收敛 ⟺ |1−β| < 1 ⟺ 0 < β < 2**。这就是临界值的全部来源：

- β = 51（腕，dt=0.005）：公比 −50 → 速度每步反号且放大 50 倍 → 自激；被力矩限幅拦住后变成有界极限环（周期 2 子步、|v| ≈ 几十 rad/s）。策略每 4 个子步采样一次（偶数），永远落在极限环同一相位上，所以 gym 里读到恒定 +41.6；
- β = 2：公比 −1，等幅振荡（临界）；
- β < 2：收敛，即物理意义上的正常阻尼。

直觉表述：显式欧拉用**上一步的速度**算刹车力、去更新**下一步的速度**；β > 2 意味着一步把速度刹穿零还过头，于是越刹越晃。

### 3.2 完整 PD：Jury 判据

对象 `I·q̈ = −Kp·q − Kd·q̇`。MuJoCo 的 Euler 与 PhysX 均为**半隐式**积分（力用旧状态算，位置用新速度更新）：

```
v[n+1] = (1−β)·v[n] − (dt·Kp/I)·q[n]
q[n+1] = q[n] + dt·v[n+1]
```

定义两个无量纲数：`α ≡ dt²·Kp/I`（刚度数，=（ω_n·dt）²）、`β ≡ dt·Kd/I`（阻尼数）。写成 2×2 递推矩阵后，特征多项式为（行列式化简后恰为 1−β）：

```
λ² − (2−β−α)·λ + (1−β) = 0
```

**Jury 判据**（离散版 Routh–Hurwitz）：二次多项式两根均在单位圆内 ⟺ 三条同时成立：

```
|1−β| < 1     →  0 < β < 2
1−T+D > 0     →  α > 0（恒成立）
1+T+D > 0     →  4−2β−α > 0  →  β < 2 − α/2
```

合并：**稳定 ⟺ 0 < β < 2 − α/2**，即 kd 上界 = `(2 − α/2)·I/dt`。

数值例（dt=0.005）：

- 腕：α = 0.005²×5/1.99e-4 = 0.628 → kd < (2−0.314)×1.99e-4/0.005 = **0.067**
- 踝roll：α = 0.005²×40/3.87e-4 = 2.58 → kd < (2−1.29)×3.87e-4/0.005 = **0.055**（且 α=2.58 意味着纯弹簧项 ω_n·dt = 1.6 已贴近单位圆边界——这是"踝roll 靠降 kd 救不了"的出处）

临界阻尼 `Kd_crit = 2√(Kp·I)`、固有频率 `ω_n = √(Kp/I)` 为标准二阶系统公式，无量纲阻尼比 `ζ = Kd/(2√(Kp·I))`。

### 3.3 低通滤波为何救不了轻惯量关节

EMA 滤波 `v̂[n] = (1−c)·v̂[n−1] + c·v[n]` 的传函为 `H(z) = c/(1−(1−c)z⁻¹)`。颤振分量是周期 2 的交替信号，对应 z = −1（Nyquist 频率 fs/2），增益：

```
|H(−1)| = c/(2−c)
```

滤波后的等效 β_eff = `Kd·[c/(2−c)]·dt/I`。令 β_eff < 2 解出 c，再换算 τ = dt/c、f_c = c/(2π·dt)：

| 关节 | β（显式@0.005） | 需要的滤波带宽 | 关节固有频率 ω_n/2π | 结论 |
|---|---|---|---|---|
| 腕roll | 50.4 | ~2.4 Hz（τ≈65 ms） | 25 Hz | 阻尼频段被整段滤死 |
| 踝roll | 25.8 | ~4.6 Hz（τ≈35 ms） | 51 Hz | 同上 |
| 肩yaw | 2.31 | ~29 Hz（τ≈5 ms） | 15 Hz | 可行，但 β 仅略超标，直接降 kd 更干净 |

对 I ~ 1e-4 量级的关节，"颤振频率 vs 工作频率"没有间隔可利用：要把 β_eff 压到 2 以下，滤波器连关节固有频率附近的真实振荡也一并滤除，还附带相位滞后。**低通此时退化为"降 Kd + 相位滞后"，劣于直接降 Kd。**

### 3.4 理论出处

- **β < 2 本体**：显式欧拉的绝对稳定域。数值分析标准内容（测试方程 ẏ = λy，稳定 ⟺ |1+λ·h| ≤ 1；Dahlquist 刚性问题理论）。同一结论在数字控制中即"离散极点位于单位圆内"。
- **Jury 判据**：E. I. Jury (1961)。见任一本离散控制教材：Ogata《Discrete-Time Control Systems》、Åström & Wittenmark《Computer-Controlled Systems》。后书专门讨论的正是本问题：采样系统中速度（微分）反馈在 Nyquist 附近自激。
- 这也是 PhysX 与 MuJoCo 均把关节 `damping` 属性实现为**隐式积分**的原因——引擎作者遇到过同一件事。

### 3.5 线性理论的边界

线性判据只判定"稳定/不稳定"。不稳定之后走向何方取决于非线性与求解器：

- **有界极限环（gym）**：力矩限幅 + PhysX 求解器耗散把发散兜住，形成对称饱和的极限环 → 关节锁死（净位移为零）；
- **发散（MuJoCo 200Hz）**：踝的交替颤振与接触求解器耦合，0.11s 内数值爆炸。

同样的 β=25.8（踝roll @0.005）在两个引擎里命运不同，即由此解释。

## 4. 有效转动惯量 I_eff 的计算方法

### 4.1 定义与代码

I_eff 取**质量矩阵对角元**——"其余关节全部锁定时，该关节单独转动的等效惯量"（标准 composite rigid body 含义）。计算代码：

```python
import mujoco, numpy as np
m = mujoco.MjModel.from_xml_path('.../g1_23dof.xml')
d = mujoco.MjData(m)
d.qpos[7:] = default_angles      # 必须设为训练默认站姿, 见 4.2
d.qpos[2] = 0.82
mujoco.mj_forward(m, d)
M = np.zeros((m.nv, m.nv))
mujoco.mj_fullM(m, M, d.qM)
I_eff = np.diag(M)[6:]           # 前 6 个 dof 是 floating base, 之后按关节顺序
```

物理上，I_eff = 该关节子树（下游所有连杆）绕关节轴的惯量，由 URDF/XML 中各连杆的 `mass` + `inertial`（pos/quat/diaginertia）算出。例：踝roll 的 I_eff = 3.87e-4 kg·m²，就是 0.608 kg 的脚绕踝roll 轴（脚的长轴方向、质心偏轴 16.4 mm）的惯量：`I ≈ 2.18e-4（主惯量最小轴）+ 0.608×0.0164²（偏轴项）`。

### 4.2 姿态依赖性（重要）

子树包含多个连杆的关节，其 I_eff 随姿态变化：

| 关节 | 子树 | 姿态依赖 |
|---|---|---|
| 踝、腕、肘 | 单连杆（或近乎） | 基本不依赖 |
| 膝、髋 | 整条腿 | 绕自身轴不变（子树绕轴旋转不改变对轴的惯量） |
| 腰（含双臂）、肩（含前臂手） | 多连杆 | **依赖姿态**：肩yaw 在屈肘 1.2 时 I=4.33e-3，手臂伸直时 ≈0.025（差 6 倍） |

**校核规则：按最小惯量姿态（最坏情况）校核 β。** 本文所有表格均在训练默认站姿（elbow=1.2、shoulder_roll=±0.08）下计算，即接近最坏情况。

### 4.3 armature 的作用

MuJoCo 的关节 `armature` 直接加在质量矩阵对角上：`I_total = I_link + armature`，β 相应缩小。它模拟的是电机转子惯量折算到关节侧的等效惯量（转子惯量 × 减速比²），是真机每个关节实际存在的物理量。IsaacGym 侧对应 `asset.armature` 配置（`asset_options.armature`）。

## 6. 12dof 为何没有此问题（armature）

`g1_12dof.xml` 第 5–7 行（**官方模型家族中唯一的此类设置**，29dof 全系列 / dual_arm / 23dof_rev_1_0 均无）：

```xml
<default>
  <joint damping="0.001" armature="0.01" frictionloss="0.1"/>
</default>
```

它给每个关节加了 armature = 0.01 kg·m²。证据链：12dof 与 23dof 的踝部连杆参数、树结构、关节锚点完全一致，唯三处 M 对角元差值精确等于 0.01（knee 1.256e-1 = 1.156e-1 + 0.01；ankle_pitch 1.278e-2 = 2.777e-3 + 0.01；ankle_roll 1.039e-2 = 3.871e-4 + 0.01）；编译后 `dof_armature` 唯一值分别为 [0.01] 与 [0.]。

对踝的作用（增益 kp=40/kd=2 与 23dof 完全相同，部署同为 0.002×10）：

| 关节 | I（无 armature） | I（+0.01） | β@0.005 无/有 | β@0.002 无/有 |
|---|---|---|---|---|
| ankle_pitch | 2.78e-3 | 1.28e-2 | 3.60 / **0.78** | 1.44 / **0.31** |
| ankle_roll | 3.87e-4 | 1.04e-2 | 25.8 / **0.96** | 10.3 / **0.38** |

即：**12dof 在 MuJoCo 里部署成功，是因为它的模型文件把每个关节的 β 压到了 0.4 附近，对频率变化免疫**——而非增益不同（完全相同）或频率运气（同为 0.002×10）。

注意：12dof 的**训练侧**（IsaacGym + URDF，asset.armature=0）同样没有 armature，其踝在训练中同样焊死——它是"训练焊死 / 部署稳定能动"的错配走过来的，且策略容忍了这种错配。23dof 走不稳的差异主要来自臂通道与整体鲁棒性。

## 7. 修复记录与验证数据

### 7.1 部署侧（已完成，2026-08-29）

1. **`g1_23dof.xml` 加 default 块**（与 12dof 完全一致）：`<joint damping="0.001" armature="0.01" frictionloss="0.1"/>`，含 floating base 在内全部 29 个 dof 生效（12dof 一直如此，无害）。
2. 效果（同一策略 model_41000，显式 PD）：

| 配置 | 加 armature 前 | 加 armature 后 | 腕子步 \|q̇\| max |
|---|---|---|---|
| 0.005×4（200Hz 物理） | 0.11s 数值爆炸 | **行走 2.44s 后摔倒** | 2.9e6 → 4.0 |
| 0.002×10（500Hz 物理） | 0.54s 摔倒 | **1.62s** | 291 → 3.9 |

（对照：隐式阻尼方案为 0.66s / 0.68s，结论一致但未采用，见 7.3。）

### 7.2 训练侧 kd 重配（已完成，待重训）

`g1_23dof_config.py` control 段：`shoulder_yaw` kd 2 → 1.4（β 2.31→1.62），`wrist` kd 2.0 → 0.05（β 50→1.26）；`deploy_mujoco/configs/g1.yaml` 的 kds 臂段同步为 `2, 2, 1.4, 2, 0.05`。实现要点：增益匹配循环遍历 `stiffness.keys()` 做子串匹配、后写覆盖，因此 `'shoulder_yaw'` 键须**同时**加入 stiffness 与 damping 两个字典，且排在 `'shoulder'` 之后。

**注意**：此配置与现役 model_41000 的训练物理（kd=2，臂焊死）不自洽，需重训后生效；旧策略配新 kd 属于混合条件，仅作参考。

### 7.3 已否决的方案

- **速度反馈低通**（τ≈10ms）：对 I~1e-4 关节退化为"降 kd + 相位滞后"（3.3 节），撤回；
- **隐式阻尼**（`m.dof_damping[6:] = kds`，去掉显式项）：实验验证任意 dt 无条件稳定（200Hz 0.66s、500Hz 0.68s，腕子步 q̇ 4.0–4.6），数值上最优；因顾虑与真机关节特性的一致性暂不采用，保留为备选。

### 7.4 待办

- 用新 kd 重训（臂部通道将首次"真的动、真的被学到"）；
- 向 Unitree 确认各关节转子折算惯量（armature 真值）与驱动器内环阻尼实现方式，据实校准 XML armature 与训练 `asset.armature`；
- 可选：臂 armature 单独取小值（≥2e-3 即满足稳定，4e-3 留余量），腿保持 0.01。
