### v3.3 失败与回滚（model_40000，08-31）

四项改动（相位冻结 + 纯转采样 25% + alive 0.5 + straight_yaw）训完，**站桩塌方**：model_40000 在 xy=0 的全部模式（spawn 站/切0 站/纯转段）以 −2~−5 rad/s 剧烈负向搅拌；行走段正常（vx 0.56）。诊断链：①TB 健康（tracking 2.16、ep_len 993、straight_yaw 收敛 −0.013——直行实际修好了），但 2.16 恰等于"75% 样本 0.95 + 25% 纯转样本全挂"的算术；②**训练态复现**（obs 噪声开 + act() 采样）：站桩 ωz=0 也搅拌 −3.5→−2.2 rad/s，纯转 ±0.35 → wz≈0 两者都没学会——不是推理伪影，是权重学坏；③对照指纹：旧权重+冻结相位的站桩只会漂移成慢走不搅拌，搅拌盆地产自训练。

**根因**：纯转采样把 xy=0 区域的样本从 ~1% 站桩翻转为 96% "要转"，但原地转本身没学出来（卡进"存活但不转"的搅拌盆地：alive 0.5/s 无终止风险，零 tracking 也活得下去），失败的"xy=0→动"关联把站桩一并带走；相位冻结削弱旧站桩习惯是帮凶。**回滚**：纯转采样撤销（转向经验稀释保留），相位冻结/straight_yaw/alive 0.5 保留，**从 model_35000 重启**（40000 权重带毒不留）。原地转向留待专项设计（候选：腰/髋 yaw 参考加强、相位慢速档、或不做纯转用弧线转）。

运维教训：日志根目录放了 `Aug30_22-33-32_.zip` 备份会让 `--resume` 的"挑最新目录"逻辑崩掉（把 zip 当 run 目录）；`--checkpoint` 参数是**数字**（拼 model_{}.pt）不是文件名。

## 5. 重训（新 kd 物理下）可复议项

以下调整的**动机建立在旧物理伪影上**，新 kd（肩yaw 1.4 / 腕 0.05）下前提已变：

1. **dof_vel 的 env 重写（只收腿+腰）**——理由是"臂 8 dof 的读数是冻结伪值 41.7"。新物理下臂真的会动、读数真实，是否收回统一税制可复议。
2. **shoulder_yaw_pos / wrist_pos 护栏罚**——当初是给"半焊死"关节设的防漂移护栏；新物理下两关节可控，罚保留合理，但力度（−5 / −1）可重新标定。
3. 9efd165 的 wrist kd 0.5→2.0 已被 β 分析取代（现 0.05），相关注释已更新。
